# artasimn

Редизайн artasimn.com. Статический сайт без сборки — чистые HTML/CSS/JS.

## Локально
```
python3 -m http.server 3000
```
→ http://localhost:3000

## Деплой на Vercel (бесплатно)
1. https://vercel.com/new → импортировать этот репозиторий.
2. Framework preset: **Other**, Build Command: пусто, Output Directory: пусто (корень).
3. Deploy.

## Структура
- `index.html` — каркас (шапка, меню, футер)
- `styles.css` — вся вёрстка
- `app.js` — роутинг по хэшу, каталог, страница товара, корзина, закладки
- `data.js` — **товары**: название, цена, размеры, описание, фото
- `assets/` — иконки, курсор, символ на фон, фото товаров

## Как поменять контент
- Товары и тексты страниц («о создателе», «оферта» и т.д.) — в `data.js`.
- Фото товаров — положить в `assets/products/` (jpg/png/webp) и прописать пути в `data.js`.
  Сейчас там временные заглушки-svg.
- Логотип — файл `artasimn-logo.svg` в корне репозитория. Его пока нет:
  залей его — и он подхватится сам (сейчас вместо него стоит текст ARTASIMN).

## Иконки и шрифты
- Иконки, курсор и символ берутся из оригинальных файлов в корне
  (`bookmark.svg`, `basket.svg`, `view with models.svg`, `view with products.svg`,
  `cursor-artasimn.svg`, `short symbol.svg`) — они не менялись.
- Шрифт — Courier New из `assets/fonts/` (regular/bold/italic), подключён через @font-face.
- Фавикон — `assets/favicon-white.svg`: белая версия `favicon-artasimn.svg`.

## Мелочи
- Курсор — `assets/cursor-artasimn.svg`, активная точка = верхний кончик крестика (5 0).
- Закладка появляется в углу фото при наведении на товар: клик — иконка становится
  полностью чёрной и товар уходит в корзину (размер берётся первый из `sizes`).
- Футер показывается только на главной (в каталоге).
- Фото товаров на главной — строго квадратные.
- На странице товара: горизонтально листаются фото товара, вертикально — сами товары
  (scroll-snap, как на yeezy.com). Работают стрелки, трекпад и перетаскивание мышью.
